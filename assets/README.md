# Assets

## Audio, Font, Images

The audio, font, and image assets used in this project are **not included** in this repository because some of their respective licences prohibit redistribution of the files. For the sake of consistency and safety, all assets used in this project have been made unavailable in this repository.
See the [CREDITS.md](CREDITS.md) in the top-level directory of this project for information about the assets used, their creators, sources, and licences.

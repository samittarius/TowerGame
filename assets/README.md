# Assets

## Audio, Font, Image

The audio, font, and image assets used in this project are **not included** in this repository because some of their respective licences prohibit redistribution of the files. For the sake of consistency, all assets used in this project have been made unavailable in this repository.

See [CREDITS.md](CREDITS.md) in the top-level directory of this project for information about the assets used, their creators, sources, and licences.

If you wish to compile and run the game, create the following directory structure:
```text
assets/
├── audio/
│   ├── background.mp3
│   ├── hit.wav
│   └── rip.wav
├── font/
│   └── BoldPixels.ttf
└── image/
    ├── axe.png
    ├── background.png
    ├── bird.png
    ├── character.png
    ├── cloud.png
    ├── rip.png
    ├── section.png
    ├── tower.png
    └── turret.png 
```
